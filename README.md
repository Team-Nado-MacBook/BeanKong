# 경북대 빈강의실 앱 (MVP)

## 개요
경북대 학생들을 위한 캠퍼스 내 빈강의실 안내 앱입니다.  
- 실시간 빈강의실 정보 제공 (공개 시간표 + 학생 체크인 기반)  
- 지도 기반 UI로 가장 가까운 강의실 바로 확인 가능  
- 학습, 자습, 휴식 등 캠퍼스 내 시간 활용 최적화  

## 기능
1. **빈강의실 조회**
   - 공개 시간표 크롤링
   - 학생 체크인 기록 기반 점유 확률 계산
2. **지도 UI**
   - 현재 위치 기준 빈강의실 표시
   - 거리순 정렬 및 즐겨찾기 기능
3. **사용자 체크인**
   - 빈강의실 사용 여부 기록
   - 점유 정보 업데이트에 활용

## 사용 기술
	- SwiftUI (모바일)
	- Apple Maps SDK
	- Firebase Realtime Database

# BeanKong 데이터 구조



## **1. BuildingEntity (건물)**



| **속성** | **타입**     | **설명**                          |
| -------- | ------------ | --------------------------------- |
| id       | String       | 고유 식별자 (JSON name 값과 동일) |
| name     | String       | 건물 이름                         |
| lat      | Double       | 건물 위도                         |
| lng      | Double       | 건물 경도                         |
| rooms    | [RoomEntity] | 건물 내 강의실 목록 (1:N 관계)    |

## **2. RoomEntity (강의실)**

| **속성**  | **타입**         | **설명**                      |
| --------- | ---------------- | ----------------------------- |
| id        | String           | 고유 식별자 (건물명-호실번호) |
| room      | String           | 강의실 번호                   |
| building  | BuildingEntity   | 소속 건물 (N:1 관계)          |
| schedules | [ScheduleEntity] | 강의실 시간표 (1:N 관계)      |

## **3. ScheduleEntity (시간표)**



| **속성** | **타입**   | **설명**                            |
| -------- | ---------- | ----------------------------------- |
| day      | String     | 요일 (mon, tue, wen, thu, fri, sat) |
| classes  | [String]   | 해당 요일 강의 리스트               |
| room     | RoomEntity | 소속 강의실 (N:1 관계)              |

## **4. JSON 데이터 예시**



```
[
    {
        "name": "산격동 캠퍼스 대학원동",
        "lat": 35.900309,
        "lng": 128.6054241,
        "rooms": [
            {
                "room": "301",
                "mon": ["2B","3A","3B","7A","7B","8A"],
                "tue": ["1A","1B"],
                "wen": null,
                "thu": ["3A","3B"],
                "fri": null,
                "sat": null
            }
        ]
    }
]
```

## **5. 관계 구조 요약**

```
BuildingEntity
 └─ rooms : [RoomEntity]
       └─ schedules : [ScheduleEntity]
```

# 빈콩 사용자 매뉴얼 💾

빈콩(BinKong)은 사용자의 현재 위치를 기반으로 대학교 내에서 이용 가능한 빈 강의실 정보를 **가장 가까운 순서**로 빠르게 찾아주는 모바일 서비스입니다.

별도의 디자인과 플로우를 대폭 줄이고 **아주 빠르게 비어있는 강의실 정보**를 확인할 수 있습니다.

와이파이, 데이터 아무것도 필요없습니다.


---


## 1. 메인 화면 및 빈 강의실 바로보기 🔍

앱을 실행했을 때 가장 먼저 보이는 화면입니다. 사용자의 위치 정보와 사용 시간대에 기반하여 빈 강의실 정보를 제공합니다.


### 1.1. 건물 리스트 및 현재 거리 확인 🏫

- 메인 화면에는 사용자의 현재 위치를 기준으로 대학교의 **건물 리스트**가 표시됩니다.
- 각 건물명 옆에는 사용자와 해당 건물까지의 **현재 거리**가 표시되어, 가까운 건물을 즉시 파악할 수 있습니다.
- 

### 1.2. 조건 설정 및 검색 결과 정렬 🗂️

| **기능**       | **위치**    | **설명**                                                     |
| -------------- | ----------- | ------------------------------------------------------------ |
| **조건 설정 ** | 화면 상단   | **요일**과 **시간**을 선택하여 원하는 검색 조건을 설정합니다. (기본값 자동설정, 변경가능) |
| **결과 표시**  | 건물 리스트 | 설정한 요일/시간에 **사용 가능한 빈 강의실이 있는 건물**만 필터링되어 표시됩니다. |
| **정렬 기준**  | 건물 리스트 | 표시되는 건물들은 사용자로부터 **가까운 순서대로** 자동 정렬됩니다. |


---


## 2. 강의실 상세 정보 확인 📑

메인 화면에서 원하는 건물을 선택하여 해당 건물 내의 이용 가능한 호실 및 시간표를 확인할 수 있습니다.


| **단계**  | **동작**                               | **확인 가능한 정보**                         |
| --------- | -------------------------------------- | -------------------------------------------- |
| **1단계** | 메인 화면에서 원하는 **건물**을 클릭   | 해당 건물 내에서 사용 가능한 **호실 리스트** |
| **2단계** | 호실 리스트에서 원하는 **호실**을 클릭 | 해당 호실의 **사용 가능한 빈 강의실 시간표** |


---


## 3. 지도 탭 활용 🗺️

지도 탭을 통해 캠퍼스 전체의 강의실 위치와 이용 가능 여부를 시각적으로 확인할 수 있습니다.


- 앱 하단의 **`지도` 탭**을 클릭하여 지도 화면으로 이동합니다.
- 지도에서 각 **건물의 실제 위치**를 확인할 수 있습니다.
- 지도를 통해 현재 이용 가능한 빈 강의실이 있는 건물을 한눈에 파악할 수 있습니다.
  

---


## 4. 즐겨찾기 (선호 강의실 등록) ⭐️ 

자주 이용하거나 확인이 필요한 강의실을 즐겨찾기에 등록하여 접근성을 높일 수 있습니다.


### 4.1. 즐겨찾기 등록 방법

즐겨찾기는 다음 두 가지 방법 중 하나로 등록할 수 있습니다.

1. **지도 화면 이용:** 지도 탭에서 원하는 강의실(건물)을 **길게 꾹 눌러서** '즐겨찾기 추가' 메뉴를 선택합니다.
2. **상세 페이지 이용:** 호실을 클릭하여 진입한 **강의실 상세 페이지**에서 화면 상단의 **별(⭐) 아이콘**을 클릭합니다.
   

### 4.2. 즐겨찾기 확인

- 즐겨찾기에 등록된 강의실은 **메인 화면의 건물 리스트 가장 위쪽**에 별도 섹션으로 고정되어 표시됩니다.
  

### 4.3. 즐겨찾기 삭제

- 즐겨찾기 리스트에서 **왼쪽으로 스와이프** 또는 **상세 페이지에서 별을 다시 눌러** 없앨 수 있습니다.
  

---
